桌面版 **1.8.2**，安卓测试版 **0.2.0**。本仓库保存程序源码、安卓工程、移动端迁移方案、内置目录数据和第三方许可。

安卓应用在手机上独立运行，复用找书与打包引擎，支持番茄雷达每日更新、候选选择、批量导入、任务记录、内置 TXT / EPUB 阅读器、系统文件保存和分享。内置海岸晨光、林间微雨、星夜远山、雨夜窗景四种离线动态景色，以及对应的绿色和黑夜界面。最低 Android 7.0 / API 24，包含 arm64-v8a 与 x86_64；当前已在 Android 15 的 x86_64 模拟器验证，尚未验证实体 ARM 手机。

## 交互反馈

1.8.2 延续轻触玻璃、柔和水波与连续选书组合，并将雷达面板进出、榜单切换和选书亮边过渡调至半秒。选书后的搜索与面板退场同时进行。雷达首次加载显示卡片占位，切换筛选保留旧卡片并提示正在读取；读取失败可原位重试。

选书后立即标出“已选定”和作品名称，进入主搜索时即显示同一本书的等待卡片；找书、获取、打包、完成四个阶段跟随真实任务更新，完成后显示勾选与下载入口。请求未能开始时保留书名与原位重试入口。系统开启减少动态效果时停用水波、位移和过渡，文字状态仍可使用。详情见“交互反馈说明.md”。

## 番茄雷达

右上角“番茄雷达”打开内置扫榜面板，支持男频／女频、阅读榜／新书榜、分类、完结状态、最低在读人数，以及书名／作者检索。分类在读合计和书名热词可以点击筛选；列表按在读量或各分类内名次排序，支持继续加载。

点击“搜索此书”会携带准确书名和作者进入原有找书流程，同名作品继续按作者区分。榜单仅提供选书信息，是否有可获取文件由原有书源决定。

随包带有 2026-10-13 的四份本地快照，合计 740 条榜单记录；界面显示实际快照日期，不冒充实时榜单。点击“刷新当前榜”从番茄公开榜单页更新所选频道与榜型，后台显示分类进度；网络失败或返回无法解析的数据时保留旧快照。已有两个日期的同榜快照时，显示相对于上份快照的分类内名次变化及新上榜标记。

该功能直接复用 Fanqie Radar 0.3.0 的读取分析内核，保留 MIT 许可与原作者署名，无需另开雷达服务或安装新依赖。用户更新数据保存在“番茄雷达/榜单”，不影响下载任务。接入范围见“番茄雷达接入说明.md”。

## 启动和使用

双击“启动书包.cmd”，在打开的页面中输入书名，停顿后搜索框下方自动展开书名建议，支持补全后续书名和错字匹配。点击建议先填入完整书名，再点击“搜索”或按回车，程序开始查找、获取并打包；没有确定匹配时显示结果候选，点击结果候选即可继续获取。

- 获取期间可以停止。
- 成功后可以下载书包或打开文件夹。
- 已确认有缺页、占位或串文的文件会显示问题提示，点击“修复正文”重新获取；检查报告可直接打开对应旧任务。
- 失败时可以查看原因并重新获取；同名书可输入“书名 | 作者”。
- 候选列出书名、作者、作品平台和已知分类；刷新页面或重启程序后仍可继续选择。
- 自动匹配后仍保留“其他候选”折叠入口，获取中和完成后都可改选；仅切换这一项，其他任务继续，新书包按当前选择重新打包。
- 点击结果右上角的关闭按钮收起结果。
- 刷新页面会保留当前页正在查看的结果；关闭网页不影响后台下载。

输出仍保存在“书包输出”，每次搜索对应一个文件夹，包含书籍、压缩包和下载报告。原有书源配置、任务记录与已下载文件继续沿用。

## 正文获取与续抓

- 优先使用作品页实际提供的整本 TXT／TXT 压缩包，支持 ZIP 中的 GB18030、UTF-8 等文本；同时识别 TXT 下载中转页及 `type=txt` 的 PHP 下载链接。爱下电子书的整本 ZIP、77读书的下载页已接入，不再漏过整本入口而请求每个章节页面。
- 整本文件按当前作品目录的唯一完整标题定位章节，允许忽略目录序号与排版标点；标题不一致、重复不明或明确占位的章节继续并发获取。整本链接失效、返回网页或无法与目录对应时，同一本书自动回退章节获取，不重复等待同一失效文件。
- 爱下 TXT 的连续目录序号还能保留网页目录漏掉的章节：只在相邻已匹配目录项之间补入文件中实际存在的独立章节，不凭章号替换正文；跨批次复用仍保留这些补入项。
- 整本导入的章节一次写入“整本正文”缓存文件，并用“整本索引”定位，避免为数千章分别创建文件。补抓章节继续保留独立缓存；停止后已提交的有效部分可以续用。旧任务续取时会补查整本入口。
- 普通章节获取默认每本 6 路并发，章节和书源请求共享 8 个网络名额；单章分页依次读取，最终按原目录顺序写入。待处理队列最多保留两倍工作线程数的章节，文件写入与网络读取分别进行。
- 相同来源、同书名和同作者的有效章节缓存可跨批次复用；只使用已完成、没有已确认正文问题且采用新版导出的任务缓存。新任务仍获取目录，新章或标题不一致的章节重新读取。检索和目录短时缓存 2 分钟，空结果及其候选缓存 30 秒，书源规则变化后不沿用旧规则的缓存。
- 先处理服务器返回的 gzip／deflate，再按字符编码读取页面，兼容声明 identity 后仍发送 gzip 的来源。
- 支持时请求 gzip／deflate 压缩传输；404 等永久错误直接尝试补抓，不重复等待同一个失效地址。补抓目录按规范化完整标题和去章号标题预建索引，不逐章重复扫描整份目录。
- 分页除了“下一页”文字，还会读取实际链接中同一章节的 `_2.html`、`_3.html` 图标按钮；不会把下一章误并入当前章。
- 爱下电子书使用专门的目录区域，保留没有“第几章”字样的番外、后记及附记，避免因标题形式不同而漏取。
- 识别“正在手打，请刷新”等明确占位提示。遇到缺损会按书名、作者及唯一章节标题查找其他来源的对应章节；补抓来源记录在 JSON 报告中。无法核对或仍为占位内容时保留失败原因。
- 有效章节按页面地址保存在各批次的“章节缓存”中，停止、网络重试后继续使用；新建搜索任务会复用同作品的有效缓存，并在自己的目录保留副本。
- 旧导出文件的已知占位章节可以单独补抓，其余有效章节保留。旧文件若已确认漏取分页，则并行获取该来源章节的全部分页，按原目录顺序汇集；停止后保留有效章节缓存。
- 2026-10-24 至 25 日直接阅读下载结果时，发现御书网同一标题下混入其他作品正文，因此默认停用；爱下电子书优先，77读书保留为后备。77 的《牧神记》页面本身也有漏字，正文返回非空不能证明版本可靠。已有文件若确认串文，重试会排除原来源，按完整书名和作者重新查找，不复用该来源的正文缓存。
- “下载检查.md”列出已检查的本机结果及直接打开任务的链接。已确认缺损的结果不再显示为完整成功，现有文件可下载查看，也可继续修复。
- 这些检查覆盖明确错误提示、章节定位和分页规则；任意串文不能仅凭关键字可靠识别，仍需直接阅读或其他版本核对。未逐字对照官方全书。失效来源、过期证书和来源本身缺章仍可能导致失败。

页面轮询仅返回显示进度、结果和改选所需的数据，完整目录和修复诊断保留在任务记录及下载报告中。需要完整状态的本地脚本可读取 `/api/state?full=1`。本地受控样文的串行、并发及缓存用时见“加速验证.md”，其比例不代表真实网站的固定提速。

1.7.5 真实获取《牧神记》的 1917 个目录项：1905 项由整本文件导入，12 项因标题差异补抓，正文获取、导出和打包共约 11.6 秒；单次整本传输约 2.1 秒。它是本机一次实测，不保证所有书籍或网络条件都达到相同用时，详见“批量抓取验证.md”。

## 搜索框候选抽屉

- 输入至少 2 个字并停顿 350 毫秒后展开；本地目录、本地书库和已有检索记录先显示，在线书源及维基文库结果随后补入。
- 完整同名、前缀补全、书名包含和错字建议分别排序，最多显示 8 项。同样的前缀及平台核实等级内，按匹配书名的规范化长度优先展示长书名；目录别名也参与加权，标点不增加长度。完整同名仍然优先，作者筛选与错字相似度规则继续沿用。
- 点击建议回填书名；已知作者会随本次搜索提交，用于区分同名书。输入过程中仅查询书名，不建立下载任务，也不读取正文。
- 方向键选择建议，回车回填；没有选中建议时，回车直接搜索。Esc、Tab、点到外部或清空输入会收起抽屉。
- 中文输入法组词期间不查询，确认文字后再开始匹配。快速修改输入时旧结果不覆盖新结果。
- 抽屉沿用 28px 模糊、170% 饱和度、默认 10% 白膜、1px 亮边及 SVG 边缘折射；按可见视口与“海面调节”按钮实际位置限制高度，横屏同样保留底部间隔，空间不足时向上展开。旋转、缩放和软键盘改变视口时重新计算。
- 抽屉显示书名、已知作者、作品平台和分类，去除标题、数量、匹配类型、箭头及下载书源名称。玻璃边框固定在外层，候选在内层滚动，避免边缘随滚动出现横线。

本地文件名索引缓存 10 秒；在线建议缓存 2 分钟。在线书源并行查询并限制等待时间，空结果时使用有限关键词补查。没有建议或来源暂未响应时，仍可直接搜索原书名。没有增加第三方依赖。

## 作品平台与下载书源

作品平台单独记录：输入候选、搜索结果和报告中标出“番茄”“起点”等，并显示已知的网文分类。平台标签依据官方作品记录，不用下载站名称、小说风格或书名相似度猜测。

- 平台核对使用完整书名或已知别名加作者；同名不同作者分别处理。缺少作者或没有可靠记录时显示“平台未核实”。
- 相同前缀的候选优先显示已核实的网文，同一核实等级内长书名靠前；平台目录在截取候选前也应用这一顺序，避免长书名被旧的录入顺序挤出。错字匹配仍以相似度为先。
- 初始目录包含 795 条作品平台记录：740 条来自本地保存的番茄官方榜单快照（2026-10-13），55 条由起点官方作品检索核对（2026-10-24）。它们用于作品身份检索，不代表最新榜单或完整平台书库。
- 在线联想优先查询官方作品目录。起点目录读取公开检索页中的书名、作者、分类和作品编号；番茄官方检索可用时也会补充。新增官方记录保存在“平台索引.json”，重启后沿用。
- 一部作品在多个官方平台有记录时并列展示，不自动宣称独家或首发归属。
- 下载书源继续用于实际获取正文，但不作为作品平台显示。JSON 和 CSV 报告把作品平台、分类与下载书源分开记录。

`data/platform_catalog.json` 保存随软件分发的目录及来源说明。平台核实不要求新增确认步骤，也不阻止平台未知的书籍继续搜索。

## 书名模糊匹配

精确匹配继续优先。统一全半角、大小写、标点和 Windows 简繁转换后，使用标准库 difflib 与内置 Levenshtein 编辑距离为目录、本地书名、在线搜索结果和维基文库候选打分，无新增依赖。

直接提交“时停”“西游”等短前缀也会保留可核对的书名候选，选择完整作品后再查找正文；前缀候选不会因加权而直接自动下载。

- 相似度由 60% 的字符序列相似度与 40% 的标准化编辑距离得分组成。
- 至少 60% 才进入候选列表，最多显示 8 项；同名同作者的多个来源合并显示。
- 至少 90%，且领先次名至少 8 个百分点时，独立候选自动继续获取。
- 少于 6 字的书名、书名互为包含（可能是续作或副标题）、部卷编号不同、相近分数及不同作者的同名书保留为可点击候选；少于 3 字的名称只做精确匹配。
- 指定作者时继续按作者精确筛选。在线候选未提供作者时标为“作者待核实”，获取时读取实际作品页核对。
- 在线搜索没有候选时，仅对已响应的书源用前半、后半书名各补查一次；不对失效来源无限重试。
- 番茄和起点官方检索候选提供“前往阅读”，用于作品信息与官方阅读入口。

自动匹配和选择后的结果会显示实际书名，文件名使用实际书名；下载报告同时保留原输入、匹配书名、相似度及自动或手动选择记录。排名后的候选和当前选择编号随任务保存，刷新或重启后可在“其他候选”中改选。获取中改选会停止这一项的旧下载，再获取所选作品，不会停止或重复获取其他作品；原本同一项已获取的文件保留在输出目录，新压缩包只打包当前选择。打包期间需等待打包结束后改选。

相似度是字面接近程度，不是同一本书的概率。此功能针对错字、漏字、字序和别名；书源未返回作品、接口失效或没有全文文件等情况仍需要相应来源，不能据此宣称覆盖 95% 的搜索失败。

## 界面与动态背景

全部玻璃表面统一使用 28px 背景模糊、170% 饱和度、默认 10% 的单层白膜与 1px 亮边；主搜索按钮白膜比全局值高 9 个百分点，默认 19%，搭配白色实线边框、14px 字号和 700 字重，强化主操作。内缘光影形成厚度；SVG 位移滤镜只作用于边缘，不扭曲中心文字。旧版蓝灰渐变与多层白色底色已经去除。首页去除了侧栏、统计、说明及书源展示区。

搜索框整体放在天空区，底边位于约 30svh 上方 24px，避免压住海平线和水面反光带；显示结果时不再把搜索框移回海平线。调节端点与未核实平台文字均至少 10px。

海面使用 [Open Sea](https://github.com/d-dev0101/open-sea-skin) 的实时渲染器。本版恢复插件原始的细波纹、浪尖泡沫、反射、天空和光照材质，不再把微表面细节压成大块起伏。默认海浪大小为 56，日光为午后，与上游实拍基准一致。

点击左下角“海面调节”可即时调整：

- 海浪大小：从平静水面到涌浪。
- 日光：从黄昏、夕照、午后到正午。
- 白膜不透明度：0% 至 40%，全局默认 10%，作用于全部玻璃表面，包括搜索框、按钮、调节面板、结果面板、候选抽屉和候选按钮；主搜索按钮始终比全局值高 9 个百分点。
- 自动日光：按 12 分钟循环变化；手动拖动日光滑块会关闭自动循环。
- 平静、夕阳、涌浪预设，以及“恢复默认”。

参数自动保存在当前浏览器，刷新后恢复。旧版设置迁移时保留海浪、日光和自动循环，只把旧玻璃底色改为 10% 白膜。面板可关闭，也可按 Esc 或点击面板外收起。所有输入框、按钮和滑块均沿用玻璃材质。

镜头保持固定，最高每秒 30 帧；隐藏页面时暂停，系统要求减少动态时冻结海浪，但仍可手动调节日光。兼容的浏览器使用显卡渲染，资源随软件打包，不依赖在线加载。无法初始化渲染时使用静态预览，并提供“重新加载海面”。

推荐 Chrome 或 Edge。海面渲染会使用显卡；搜索、获取和打包不依赖海面是否加载成功。

## 书源

1.7.7 新增10组来源：笔趣阁info、香书小说、全本小说网、笔尖中文、阅读库、鸟书网、悠久小说网、笔趣阁365、轻之文库、新笔趣阁（分目录）；另为最后一组接入第八中文网镜像。默认共配置20组，其中御书网继续停用，番茄和起点提供官方作品检索。配置数量不代表可用正文来源数量，也不等于覆盖全网。

在线来源改为最多6路并行检索，整轮网络查源预算约10秒，优先来源在短暂等待后让出慢站；失败来源暂避60秒，点击重新获取可立即重试。已有平台记录能明确作者时按作者优先，同名不同作者保留为候选。分目录站会合并所有已发现的目录页，再用实际链接接上首页近期章节；不会只下首屏目录。目录分页失败会换源或报错。详细范围及实测见“扩源验证.md”。

1.7.6 增加日轻专用的“轻小说文库（公开整理）”。初始快照有4345个可识别作品，其中4002条附公开整本文件链接；目录与书名联想保存在本地，输入时不请求正文。支持完整书名、目录已有别名、前缀及错字候选，作者用于区分同名作品。

此来源的“TXT”入口实际主要是纯文字EPUB，按原格式获取并打包；可能不含插图，文件更新日期也可能早于作品最新卷。下载后核对EPUB实际书名，JSON报告分别记录文件日期和作品目录更新日期。目录有链接不代表所有地址当前都有效，也不代表最新版或全集。来源说明、更新方式及真实验证见“轻小说接入说明.md”。

依次检索自定义目录、本地书库、在线书源和维基文库。来源不可用时继续尝试其他来源。在线书源的接入范围及既有实测情况见“在线书源说明.md”；配置项并不代表当前一定可用。

默认本地书库为程序目录的“本地书库”；上级存在“抓取结果”时也会纳入。个人书源设置保存在“书源设置.json”，最近的在线检索状态保存在“书源状态.json”。升级继续使用这些配置。

## 保留的后台功能

批量清单、链接导入和书源配置接口继续保留，首页不再提供它们的表单。既有调用可继续使用：

| 接口 | 用途 |
| --- | --- |
| 读取或提交 /api/sources | 本地书库、自定义目录及在线书源规则 |
| 提交 /api/start | 按书名或链接建立批量任务 |
| 提交 /api/suggest | 按 query 查询书名建议；online 开启在线补查 |
| 读取 /api/state | 任务记录 |
| 提交 /api/retry、/api/cancel | 继续未完成任务或停止 |
| 提交 /api/choose | 以 id、task_id、candidate_id 选择候选并继续该本 |
| 读取 /api/archive/任务编号 | 下载书包 |

批量接口的 text 字段支持一行一本，mode 为 titles 或 links；单次并发仍支持 1 至 6 本。示例格式见“示例清单.csv”“示例链接清单.csv”和“书源目录示例.json”。

## 运行与文件

需要 Python 3.10 或更高版本；本机已有 Python 3.12。后台使用标准库，无需安装第三方 Python 依赖。海面所需的脚本已放在 web/ocean，其中保留原作者和 three.js 的许可及来源说明。

可手动运行 python app.py --open，或用 --port 指定端口。服务仅监听本机，启动时复用同一程序目录的运行实例。地址记录在“运行地址.json”，异常记录在“运行日志.log”。关闭后台可向 /api/shutdown 提交空对象。

仅凭书名不能保证当前书源存在可获取的版本。文件格式和传输检查不证明小说无缺章。个人配置、历史记录和下载内容不包含在分发包中。
