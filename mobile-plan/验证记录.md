# 移动端方案与原型核验

日期：2026-10-25。范围：方案、独立交互原型、随包快照及原创演示文件。

## 已核实的事实

- 当前桌面基线为 1.8.2；方案按实际 HTML、路由、Engine、书名归一化和雷达代码编写。
- 直接确认当前仅绑定本机、同时运行一批任务、Windows 繁简转换、主机文件夹动作及目录式存储，均已在迁移方案中给出处理方向。
- 原型从随包四份 2026-10-13 快照构建：男频阅读 190、男频新书 190、女频阅读 180、女频新书 180，共 740 条榜单记录。只导出必要的公开目录字段，未读取个人下载和任务。

## 可执行的验证

针对性脚本为 tools/mobile_smoke.mjs，运行于独立 Chrome 配置和临时预览服务中。

- 触屏事件走通底部导航，检查实际水波及最小 44×44px 导航触控区。
- 四榜切换、日期显示、分类/状态/最低在读/排序筛选、空结果、清除筛选和追加分页继续可用；分页保留原卡片节点。
- 筛选面板动画为 500ms；系统减少动态后停用海面、卡片和面板动画，关闭即时完成。
- 从雷达选择《神通者》/天蚕土豆，作品信息准确进入演示任务；停止后刷新页面，书名和任务保留，继续后完成。切换页面不停止演示任务。
- 确认导出按钮实际产生 ZIP 文件；另用 Python zipfile 核对目录、CRC 与 UTF-8 内容，文件明确写明不是所选榜单作品正文。
- 外观预设与白膜值在刷新后保留；连接中断状态保留输入，支持原位重试；逐行书单和带引号 CSV 文件完成导入预览。
- 检查 390×844、320×720、430×932、844×390、390×530 和桌面 1440×1000。前五种覆盖窄屏、横屏和缩短视口；页面无横向溢出，底部导航可见，筛选面板在动画结束后处于视口内。短视口输入框保持 16px，搜索操作不被底部导航覆盖。
- 浏览器未捕获未处理的脚本异常。具体运行记录在 validation.json。
- 另以 file 地址直接打开 prototype/index.html，页面、海面、榜单和导航正常工作，不需要常驻预览服务。

## 当前交付边界

- 这是桌面 Chrome 的移动视口和触屏模拟，不是 Android Chrome、Android WebView 或 iPhone Safari/WKWebView 的真机验收。
- 390×530 是缩短视口检查，没有真实弹出安卓或 iOS 软键盘；输入法、系统安全区和返回手势仍需真机验证。
- 任务阶段是标注清楚的演示，文件仅含原创样文。本轮未联网下载真实小说、刷新平台榜单或修改桌面任务。
- 尚未生成 APK/IPA，未部署远程任务服务，也未完成原生文件下载、系统保存、分享及锁屏后台恢复。
- 提供的预览脚本仅监听本机；自动后台预览服务未启动。原型可以直接打开，没有把现有桌面应用改成公开网络服务。
