# 移动端导航与命名

组织原则：围绕一本书从发现到保存的过程。全局只保留“找书 / 雷达 / 书包 / 设置”。

| 层级 | 规则 |
| --- | --- |
| 全局导航 | 底部固定四入口；保持文字，不只放图标；选中态同时改变图形、文字和可访问状态 |
| 页面标题 | 显示当前入口；进入任务后显示返回与任务书名，不把详情伪装成另一个主入口 |
| 任务详情 | 可从找书、雷达、书包进入；返回回到来源页面，保留该页滚动和筛选 |
| 雷达筛选 | 底部面板编辑副本；点击“查看结果”才应用，关闭不提交；回到雷达不清空条件 |
| 同名候选 | 展示书名、作者、平台；一次只选一个具体作品；作者随任务保存 |
| 状态命名 | 找书、获取、打包、已生成；文件接收后另标“已下载到此设备”，导出成功再标“已保存” |
| 操作命名 | 找书用“搜索”，候选用“选这本”，雷达用“搜索此书”，文件用“保存到文件 / 分享” |
| 次级能力 | 导入书单属于找书；来源、连接、外观属于设置；停止/重试/修复属于具体任务 |
| 返回顺序 | 先关闭筛选或候选面板，再退出任务详情，最后返回主入口；返回不取消后台任务 |
| 空与失败 | 无匹配显示空结果及修改条件入口；失败在原位显示原因与重试，保留作品和筛选 |

拟定正式路由：/search、/radar、/bags、/settings、/tasks/:id。筛选是雷达的局部状态；任务 ID 在刷新和应用恢复后保持稳定。

原型使用等价的 hash 路由，演示任务与设置只写入独立浏览器键，不读取桌面任务。

## 原型与正式能力的标注

预览外层常驻“交互原型 / 任务为演示”。原型中的保存按钮写“保存演示书包”，文件内也写明演示用途；不将模拟进度或原创样文当作真实作品获取结果。

原型未接通的在线刷新与原生设备动作必须说明当前范围，不能显示虚假的最新日期、来源健康状态或已经导出成功。
