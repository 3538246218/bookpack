# 书包安卓 0.2.0 测试版

这次补齐每日榜单更新、更多动态景色和应用内阅读。

- 番茄雷达：修复旧代码把占位 readCount=0 当作真实在读数的问题，以及个别官网页面含 undefined 导致整榜无法解析的问题。显示最新章节和采集时间，分类失败时明确标记并保留可用数据。2026-10-25 实际采集四份榜单共 740 条记录。
- 每日更新：默认注册安卓每日联网检查任务，重启手机后保留调度；打开应用时补查。设置中可关闭。后台执行受安卓省电和网络条件影响，不保证固定时刻运行。
- 四种离线动态景色：海岸晨光、林间微雨、星夜远山、雨夜窗景。林间使用绿色界面与浅绿阅读纸面，星夜和雨夜使用深色界面与阅读纸面。
- 动效状态：显示实际停播原因，原生系统动画设置变化后同步 Canvas 播放，不再要求重启应用才能恢复景色。
- 内置书架与阅读器：完成获取后可直接开始阅读，也可导入手机 TXT / EPUB。支持目录、全文搜索、字号行距、书签及跨进程保留进度。EPUB 以正文文字阅读为主，暂不显示插图或还原原始版式。

安装附件为 `bookpack-android-0.2.0-debug.apk`。包名、调试签名和架构沿用上一版，支持覆盖升级。最低 Android 7.0 / API 24，包含 arm64-v8a 和 x86_64。实体 ARM 手机尚未验证。

安装包大小 43,616,115 字节（约 41.6 MiB）。SHA-256：`b611f958c53f8fe8e24d0200f4c18a1eacd80e7c4a9bf5f3ccf5f29f31b98b3b`。

验证：11 项 Python 回归、15 项真实适配器交互检查、16 项 Android 15 模拟器原生检查通过。实际验证系统文件保存、后台传输、每日任务调用、阅读进度恢复及安卓端联网刷新。详见 [验证记录](https://github.com/3538246218/bookpack/blob/main/android/0.2.0%E9%AA%8C%E8%AF%81%E8%AE%B0%E5%BD%95.md)。

背景为本机动态绘制场景，无需另行下载视频。参考调研看过 [after-rain](https://github.com/HiliMor/after-rain) 的森林场景方向；本版未引入该项目代码或新的图形依赖。每日后台能力依据 [Android JobScheduler](https://developer.android.com/reference/android/app/job/JobInfo.Builder#setPeriodic(long,%20long)) 实现。
