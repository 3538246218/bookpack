# 书包安卓 0.4.0 融合测试版

安装一个 APK 即可找书和阅读。Legado 3.26101819 的源码已编译进书包，使用同一个应用包名和一个桌面入口，无需另外安装 Legado。

- 默认进入包内的原生阅读页，支持 TXT、EPUB 插图、章节切换及音量键翻页：音量减下一页，音量加上一页。
- 自动保存阅读副本；同一本书内容未变时直接续读，重启后保留位置，不重复导入。返回键可回到书包。
- 保留原有的简洁阅读选项，两种阅读方式分别保存进度与书签。
- 同包名、同调试签名覆盖升级，保留书包原来的任务和书籍。

**要求 Android 8.0 / API 26 及以上**，支持 arm64-v8a 与 x86_64。最低版本由此前的 Android 7 提升为 Android 8，源于本次集成的脚本引擎对 Android API 的要求。旧版安装包仍保留在此前 Release。

独立 Legado 的旧进度和书签不会自动迁入融合版；需要的数据请通过原应用的备份与导入功能迁移。融合发行的应用代码按 GPLv3 提供，保留原作者署名和许可；[对应源码与构建说明](https://github.com/3538246218/bookpack/blob/android-v0.4.0/android/BUILD.md)随本版本一同公开。应用内可离线查看完整许可，详细修改范围见 [NOTICE](https://github.com/3538246218/bookpack/blob/android-v0.4.0/android/NOTICE.md)。

附件：`bookpack-android-0.4.0-debug.apk`，75,917,698 字节，约 72.4 MiB。这是调试签名的功能测试版，尚未验证实体 ARM 手机。

SHA-256：`14b00bad8637758c13b893eb87fa5c84385d9e1264ea7f163bce955710606ac0`
