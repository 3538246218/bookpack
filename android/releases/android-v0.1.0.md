# 书包安卓 0.1.0 测试版

首个安卓独立运行测试包，内置 Python 引擎，不依赖电脑服务。支持找书、候选选择、番茄雷达、批量导入、获取打包、任务记录，以及系统文件保存与分享。

- APK：`bookpack-android-0.1.0-debug.apk`，42,613,856 字节。
- SHA-256：`f691af94d488ef4c5a86026b270b0bae8d8f6acab94e1d381a70ce5d09e4aea2`。
- 最低 Android 7.0 / API 24，包含 arm64-v8a、x86_64。
- 使用调试签名。已在 Android 15 的 x86_64 模拟器跑通实际获取、打包、系统保存、后台传输、任务与设置持久化；尚未验证实体 ARM 手机。

已知问题：动态海面在收到系统减少动效信号后停播，但开关仍显示开启；系统设置变化在当前测试 WebView 中需要重启应用进程才更新。海浪大小为 0 也会静止。问题已调查，当前 APK 尚未包含修复，详见仓库 `android/动态海面问题调查.md`。

源码同时保存桌面版 1.8.2、移动端迁移方案和第三方许可。安装及构建见 `android/安装与使用.md`。
