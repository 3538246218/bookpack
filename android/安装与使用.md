# 书包安卓测试版 0.1.0

安装包从 [GitHub 测试版 Release](https://github.com/3538246218/bookpack/releases/tag/android-v0.1.0) 下载，附件名为 `bookpack-android-0.1.0-debug.apk`。本机交付文件为项目根目录的 `书包-安卓-0.1.0-测试版.apk`，两者内容相同。

## 安装

1. 把 APK 传到手机，用文件管理器打开。
2. 如果系统提示，允许本次使用的文件管理器安装应用，再完成安装。
3. 打开「书包」。首次启动需要解压内置运行环境，请稍等。

要求：Android 7.0（API 24）及以上、64 位 ARM 手机，或 x86_64 安卓环境。手机的 Android System WebView / Chrome 需要保持更新。这个包包含手机上的 Python 运行环境，约 42.6 MB，可以独立运行；在线找书和刷新榜单需要网络。

这是调试签名的功能测试版。先用于安装和体验；尚未完成实体手机适配验证。

## 当前功能

- 找书：本地及在线书名建议、繁简匹配、候选选择、单本获取、书单或链接批量导入。
- 雷达：内置榜单快照、分类筛选、分页、选书带入搜索，以及联网刷新。页面会显示快照日期；内置数据日期为 2026-10-13。
- 书包：真实任务进度、取消、重试、TXT / EPUB 处理、ZIP 打包和任务记录。
- 手机文件：用系统文件选择器保存 ZIP，或调用系统分享面板；在设置中导入本地 TXT / EPUB。
- 交互：沿用三种外观组合、按压和波纹反馈、500 毫秒雷达切换过渡，支持减少动态效果。
- 后台：任务运行时使用安卓前台服务。退到桌面后可继续获取；系统省电策略、强行停止或进程被清理仍可能中断任务，重新打开后可查看记录并重试。

雷达的榜单信息用于发现作品；是否能获取正文取决于实际书源。发现作品不代表一定有可用全文。

## 保存与数据

完成任务后点「保存到文件」，在系统窗口选择文件夹并确认保存。只有文件写入完成后才会提示保存成功。也可以点「分享书包」，由手机选择接收应用。

任务、配置、导入的本地书和尚未导出的书包保存在应用私有目录。卸载应用或清除应用数据会移除这些内容；已经通过「保存到文件」导出的 ZIP 留在所选文件夹。

## 验证范围

验证记录保存在 `outputs/web-validation.json` 和 `outputs/native-validation.json`。原生验证使用 Android 15 / API 35 的 x86_64 模拟器，使用原创功能样文检查手机内 Python、实际获取与打包、系统保存和后台传输。实体 ARM 手机的兼容性需要实际安装反馈。

## 源码与构建

安卓工程在本目录，原桌面版代码保留。`tools/prepare.py` 仅打入程序、依赖和内置数据，不打入桌面版的真实任务、下载文件和用户配置。`web/mobile.js` 对接真实引擎，原 `mobile-plan` 交互原型仍单独保留。

当前 Windows 构建环境：`E:/dev-tools/android-sdk`、Gradle 8.11.1、JDK 21、Python 3.12。依次运行 `tools/prepare.py`、`tools/build.py`，输出位于 `E:/dev-tools/builds/bookpack-android/app/build/outputs/apk/debug/app-debug.apk`。

技术依据：[Chaquopy 安卓集成](https://chaquo.com/chaquopy/doc/current/android.html)、[Android Gradle Plugin 8.9](https://developer.android.com/build/releases/agp-8-9-0-release-notes)。第三方运行代码及许可证随 APK 打包。
