# 书包安卓测试版 0.2.0

安装包从 [GitHub 测试版 Release](https://github.com/3538246218/bookpack/releases/tag/android-v0.2.0) 下载，附件名为 `bookpack-android-0.2.0-debug.apk`。本机交付文件为项目根目录的 `书包-安卓-0.2.0-测试版.apk`，两者内容相同。同签名安装可覆盖升级，保留原来的任务与书籍。

## 安装

1. 把 APK 传到手机，用文件管理器打开。
2. 如果系统提示，允许本次使用的文件管理器安装应用，再完成安装。
3. 打开「书包」。首次启动需要解压内置运行环境，请稍等。

要求：Android 7.0（API 24）及以上、64 位 ARM 手机，或 x86_64 安卓环境。手机的 Android System WebView / Chrome 需要保持更新。这个包包含手机上的 Python 运行环境，可以独立运行；在线找书和刷新榜单需要网络。

这是调试签名的功能测试版。先用于安装和体验；尚未完成实体手机适配验证。

## 当前功能

- 找书：本地及在线书名建议、繁简匹配、候选选择、单本获取、书单或链接批量导入。
- 雷达：内置 2026-10-25 的四份榜单快照、真实在读数与最新章节、分类筛选、分页、选书带入搜索，以及联网刷新。显示实际采集时间；部分分类失败时保留该分类旧数据并标明状态，不丢掉其他分类的成功更新。
- 每日更新：默认开启，使用安卓 JobScheduler 每日联网检查四份榜单，打开应用时补查缺失日期。系统省电、网络约束和强行停止可能延后或阻止执行，不能保证每天固定时刻运行。设置中可以关闭；手动刷新仍可使用。
- 书包：真实任务进度、取消、重试、TXT / EPUB 处理、ZIP 打包和任务记录。
- 手机文件：用系统文件选择器保存 ZIP，或调用系统分享面板；在设置中导入本地 TXT / EPUB。
- 动态景色：海岸晨光、林间微雨、星夜远山、雨夜窗景，均由本机绘制并可离线使用；绿色护眼配色与黑夜配色跟随景色。显示实际播放或暂停原因；原生系统动效设置变化后立即同步。沿用按压、波纹反馈和 500 毫秒雷达过渡。
- 阅读器：已获取的 TXT / EPUB 自动进入书架，也可导入手机文件。支持章节目录、全文搜索、字号行距、书签和阅读进度恢复。EPUB 按正文阅读顺序显示文字；此版不显示插图或还原原书版式，不支持纯图片 EPUB、PDF 或 DRM 文件。
- 后台：任务运行时使用安卓前台服务。退到桌面后可继续获取；系统省电策略、强行停止或进程被清理仍可能中断任务，重新打开后可查看记录并重试。

雷达的榜单信息用于发现作品；是否能获取正文取决于实际书源。发现作品不代表一定有可用全文。

## 保存与数据

完成任务后点「保存到文件」，在系统窗口选择文件夹并确认保存。只有文件写入完成后才会提示保存成功。也可以点「分享书包」，由手机选择接收应用。

任务、配置、阅读进度与书签、导入的本地书和尚未导出的书包保存在应用私有目录。卸载应用或清除应用数据会移除这些内容；已经通过「保存到文件」导出的 ZIP 留在所选文件夹。

## 验证范围

详细结果见 [0.2.0 验证记录](0.2.0验证记录.md)。本地原始报告保存在 `outputs/web-validation.json` 和 `outputs/native-validation.json`。原生验证使用 Android 15 / API 35 的 x86_64 模拟器，使用原创功能样文检查手机内 Python、实际获取与打包、系统保存和后台传输。实体 ARM 手机的兼容性需要实际安装反馈。

## 源码与构建

安卓工程在本目录，原桌面版代码保留。`tools/prepare.py` 仅打入程序、依赖和内置数据，不打入桌面版的真实任务、下载文件和用户配置。`web/mobile.js` 对接真实引擎，原 `mobile-plan` 交互原型仍单独保留。

当前 Windows 构建环境：`E:/dev-tools/android-sdk`、Gradle 8.11.1、JDK 21、Python 3.12。依次运行 `tools/prepare.py`、`tools/build.py`，输出位于 `E:/dev-tools/builds/bookpack-android/app/build/outputs/apk/debug/app-debug.apk`。

技术依据：[Chaquopy 安卓集成](https://chaquo.com/chaquopy/doc/current/android.html)、[Android Gradle Plugin 8.9](https://developer.android.com/build/releases/agp-8-9-0-release-notes)。第三方运行代码及许可证随 APK 打包。
