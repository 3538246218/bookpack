## 范围与限制

安装包已实际安装、启动并完成上述阅读操作。最低 API 与双架构由 APK 元数据确认，尚未在实体 ARM 手机、Android 8 设备或所有厂商系统上实测。Legado 的其他功能未作穷尽验证。
